10分の基礎メニュー

覚えておこう：正しいフォームか分からない動きは、顧問や先輩のお手本を見てからゆっくり練習。速さや回数より、動きの質を優先しよう。
夜の公園では明るく平らな場所を選ぶ。暗い場所での全力移動は避け、痛みが出たら中止。

基礎ドリル

一度に全部やらず、1〜2種類を選んでOK。最初はゆっくり。

フットワーク · 3分

ドリルA：構え → 一歩 → 戻る

  1. 足を肩幅程度に開き、膝を軽く曲げる。
  2. 前へ一歩動く。
  3. バランスを保って中央の位置に戻る。
  4. 慣れたら左右にも行う。
チェックポイント
  • 足がもつれない。
  • 移動後に体勢を崩さない。
  • 戻ったらすぐ次へ動ける。

まずは各方向2回ずつ。速さは上げない。

フットワーク · 3分

ドリルB：4方向シャドー

  1. 中央で構える。
  2. 前右→中央→前左→中央。
  3. 後ろ右→中央→後ろ左→中央。
  4. ゆっくり1周から始める。
チェックポイント
  • 動いたあと中央に戻れる。
  • 足を無理に交差させない。
  • 周囲を見ながら安全に動ける。

後方への動きは慣れてから。暗い場所では行わない。

フォーム · 3分

ドリルC：オーバーヘッドの素振り

  1. 横向きに近い姿勢をつくる。
  2. 打点を頭の少し前にイメージする。
  3. 力まずゆっくり振る。
  4. 振ったあと、バランスを保って構え直す。
チェックポイント
  • 腰を反らせすぎない。
  • 打点を体の後ろにしない。
  • 肩に痛みが出る動きはしない。

最初は顧問や先輩に一度見てもらい、直すポイントを1つ決めよう。

打点 · 3〜5分

ドリルD：シャトルを捉える

  1. 周りに人や物がない場所で、シャトルを軽く落とす。
  2. ゆっくりラケット面を合わせる。
  3. 力いっぱい振らず、軽く打つ。
  4. 空振りしたら、シャトルを見ていたか・打点が近すぎないかを振り返る。

安全なスペースがない場合は省略してOK。

おすすめの進め方

最初の4週間

  • 1週目：構え・一歩動いて戻る
  • 2週目：オーバーヘッドのフォーム
  • 3週目：フットワークと素振りを組み合わせる
  • 4週目：シャトルを打ち、ミスの原因を記録

予定どおり進まなくても大丈夫。できるまで同じ基礎を繰り返そう。
